Como usar a Pesquisa Profunda

Carregar ficheiros

Arraste ficheiros de texto (.txt, .md, .html, .csv, .json, .log, .py, .js, .css, .xml, etc.) para a barra lateral, ou clique na zona tracejada.

Pesquisa simples

Digite uma palavra ou frase. Por omissão, a pesquisa ignora maiúsculas/minúsculas.

Opções de pesquisa

Case-sensitive (Aa) — distingue maiúsculas de minúsculas.
Palavra inteira — só encontra correspondências isoladas (\\bword\\b).
Regex — usa expressões regulares. Ex.: erro\\s+\\d{3}, [A-Z]{2,4}-\\d{4}.
Fuzzy (≈) — encontra palavras parecidas (Levenshtein). Tolerância de 1 erro por cada 4 caracteres.

Resultados

Cada resultado mostra até N trechos com contexto. Clique em 🔗 Abrir para ver o ficheiro completo com todas as ocorrências destacadas.

Atalhos de teclado

Enter — pesquisar
Esc — fechar janela
Ctrl+E — exportar resultados em CSV
Ctrl+F — focar a caixa de pesquisa
